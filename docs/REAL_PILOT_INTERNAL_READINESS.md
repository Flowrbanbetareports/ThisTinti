# Internal pilot readiness priorities

External contact work is outside the ThisTinti product workflow.

The internal priorities before any authorised real-data pilot are:

1. extract reviewable product rows from clear and low-contrast OCR scans;
2. preserve fail-closed numeric validation and source provenance;
3. make the 30-scenario apparel benchmark reproducible from the current branch and `main`;
4. keep real-pilot workspaces local, isolated and explicitly authorised;
5. reject incomplete ground truth, duplicated reviewers and unmeasured before/after timings;
6. export only structured, redacted results and never trigger communications from application code or CI.

Completion of these items improves product readiness but does not claim that a real company pilot has occurred.
