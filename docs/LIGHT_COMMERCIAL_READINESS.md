# Preparazione commerciale leggera

ThisTinti mantiene il proprio nucleo gratuito, locale e Apache 2.0. La preparazione commerciale non attiva un servizio gestito e non introduce account centrali, telemetria, pubblicità esterna o pagamenti.

## Elementi predisposti

- pagina amministratore **Progetto e piani** nell’app locale;
- dashboard pubblica separata sul sito ufficiale con contatore dei download degli asset GitHub, distinto da utenti e installazioni;
- riepilogo pubblico di release, stelle, fork, issue/PR e workflow recenti;
- anteprima scaricabile dell’Integration Pack con OpenAPI ed esempi Python, JavaScript e C#;
- catalogo minimo Free / Integration Pack / Enterprise;
- spazio sponsor visivo disattivato e privo di script esterni;
- configurazione di pagamento dichiarata esplicitamente disattivata.

La dashboard pubblica interroga GitHub soltanto quando viene aperta o aggiornata. L’app locale non contatta GitHub per raccogliere metriche e non invia documenti, contenuti OCR, nomi di file, utenti o attività.

## Confine della monetizzazione

Il codice già pubblicato resta disponibile secondo Apache 2.0. Un’offerta futura potrà riguardare un pacchetto mantenuto, compatibilità tra versioni, connettori, documentazione operativa o supporto separato. Non può rendere retroattivamente a pagamento i diritti già concessi sul sorgente pubblico.

## Confine legale

Non è attivo alcun checkout. Prima di attivarlo servono identità del venditore, trattamento fiscale, condizioni commerciali e verifica legale. Le condizioni possono limitare rimborsi discrezionali dopo una consegna digitale corretta, ma non possono eliminare diritti inderogabili, rimedi per mancata consegna o non conformità, né impedire reclami legittimi.
